# The Annoying Button

By Gillian Parris

The Annoying Button is a small browser game about a bright pink button that makes an ordinary click a lot more work than you expect. I wanted it to be annoying in a funny way, so each challenge asks you to interact with the button differently.

## Play

Download or clone the project, then open `index.html` in a desktop browser. Keep `index.html`, `style.css`, and `script.js` together in the same folder. Use a mouse or trackpad and a keyboard.

Start by trying to click the pink button. Watch what it does and read the clues as they appear. You’ll need to answer a riddle, figure out how long to hold the button, and look closely at five choices. The round counter keeps going as the challenges repeat with different riddles. Use **Replay** to start over.

## How it works

The project uses HTML, CSS, and JavaScript. The script tracks the number of dodges, whether the riddle is solved, and whether Shift is held. It tracks the current challenge separately from the displayed round number so the challenges can repeat while the round number keeps increasing.
